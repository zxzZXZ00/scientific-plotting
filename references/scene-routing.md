# 从已有资源中选择，而不是限制研究领域

每张图必须明确选择库中存在的 theme 与 palette，并写入 resolved-config；内置 paper、blue-red 也属于已有资源。
主题与配色可分别选择。用户显式选择优先于领域推荐和主题默认；字号、尺寸、DPI 等仍可覆盖。系列颜色只允许使用所选已有 palette 的颜色（可重排、取子集）。库外主题或配色需要先走新增资源流程，不能边绘图边临时编造并冒称已有资源，也不能悄悄替换用户指定名称。

推荐顺序：本次用户明确要求 → 用户指定图型/数据含义与已有样式的适配性 → 相同或相似的文献场景 → 借用一个清晰合适的已有主题与配色。
文献领域不是准入条件。新领域或未声明领域，仍可从现有库借用；不能因为没有同领域主题就拒绝绘图，也不能由配色推断材料、反应、实验类型或统计量。

## 自动建议与用户覆盖

scripts/scenes.py 根据文件名、CSV表头和可选 purpose 提供温和建议。purpose 可以是已知标识或自然语言用途；陌生用途回退到已有 paper 风格。任何时候 theme、palette、template 的显式值各自优先。

- spectrum（XANES/EXAFS/IR/Raman等）推荐蓝洋红；NMR/EPR/UV–vis及色谱推荐红青；mass-spectrum 推荐桃橙青绿与 sticks；electrochemistry 推荐雾蓝玫粉；bio-timecourse 推荐桃橙青绿。
- spectrum 是通用连续谱线模板，不画 marker，不拟合、不平滑、不归一化、不人为错层；严格单调的递增或递减横轴都可读入，并保留下降方向。用户显式指定其他模板仍按其要求。
- sticks 用于已有离散 m/z–强度数据，从0画竖线，不把连续扫描谱自动离散化。数据类型不明确时不能仅凭“质谱”二字决定峰型/棒型，应核对数据或用户意图。
- 连续时间/电位趋势可复用 line；已有上下界的不确定性可用 line-with-band。需要柱图、箱线、双轴、堆叠谱等时，Agent 可使用已有主题与配色写对应 Matplotlib 代码，并接入统一导出和排版检查；内置命令不会假装支持未实现的任意多面板CSV适配。
- 只有无领域的 x-y 数据时，可选择现有 paper 或其他合适主题说明“借用此风格”；不要强行赋予光谱、时间、催化或生物含义。不清楚字段/单位时核实映射，不编造。
- 普通 line 保持原有递增约束；spectrum 接受单调双方向；确有循环扫描/非单调轨迹且用户意图明确时可显式设置 data.x_order: preserve，逐行连接，不自动排序或合并点。

借用的是视觉设计，不是原文的反应条件、统计定义、误差大小、峰归属、物理结论或面板中的全部结构。

# CSV 数据约束

普通 line、spectrum、sticks 模板仅要求映射 x、y，group 可省略（作为一组 Data）。
其余有限数值、行顺序、每组至少两点的规则相同，不要求上下界。
line/sticks 默认要求 x 递增；spectrum 默认接受严格递增或递减并保留横轴方向。
data.x_order 可显式指定 increasing/decreasing/monotonic/preserve；preserve 只在用户连线意图明确时使用，不能借此隐藏未知顺序问题。
用户模板的数据约束按 user-library/catalog.md 指向的对应说明检查。

使用 UTF-8（允许 BOM）、英文逗号和第一行表头。默认使用以下长表结构：

```csv
time,mean,lower,upper,method
0,1.0,0.8,1.2,A
1,1.5,1.3,1.7,A
0,0.9,0.7,1.1,B
1,1.2,1.0,1.4,B
```

每行表示某组在一个横坐标处的一个观测或汇总结果：

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| time | 横坐标 | 有限数值，同一组内严格递增 |
| mean | 折线纵坐标 | 有限数值 |
| lower | 阴影下界 | 有限数值，lower ≤ mean |
| upper | 阴影上界 | 有限数值，mean ≤ upper |
| method | 分组名称 | 非空文本 |

列名可通过配置映射，不必固定为这些名称。映射的五列必须不同。
至少一行数据；不接受空字段、NaN、inf、重复表头或字段数量不符。
额外列忽略；保留每组原始顺序，不自动排序、补值或平均。
每组至少两个点。不同组可以有不同的横坐标。

上下界必须由用户数据提供。说明它们代表标准差、置信区间或其他范围；
绘图代码只展示上下界，不推断统计含义。单位通过轴标签说明。

# 文字、刻度与图例约束

根据用户对实际绘图的反馈更新。封闭图框规则适用于所有现有和新增主题；字号、配色与标记的具体默认值按主题设置。

## 资源、用途与导出

- 每张图必须采用库中实际存在的主题与配色；用户指定优先。没有同领域资源时借用适配的已有风格，不临时编造主题/配色，不把借用风格当成科学类型判断。详见 scene-routing.md。
- 安装完成后主动说明用法、现有主题示例和输出位置，并在可能时展示现有预览图；先按 installation.md 验证依赖与 Arial。
- 普通绘图和独立脚本统一通过 exporting.py 导出到本次工作空间/sci_plots，默认 png/svg/pdf 三格式各归对应子目录，basename 来自实际输入文件；换工作空间重新取目录。只有用户明确要求时覆盖，详见 output-policy.md。

## 字体、图例和误差棒

- 所有现有和新增图默认使用 Arial 正体，包括轴标题、刻度、图例、面板编号和注释。只有明确需要斜体的科学符号、基因名等使用 Arial 斜体；不得整段沿用参考图的斜体字体。
- 参考图重绘须使用真正的 Arial 文本，不能把原字体的字形轮廓保留为路径后声称已统一字体。字号按最终输出尺寸检查，不能仅提高 DPI。
- 图例标记与参考图及数据系列一致。“短线＋圆点”的图例应显式构造 Line2D，不得直接展示 ErrorbarContainer 导致额外端帽、竖线挤在标记上。
- 误差棒须核对中心位置、上下端点、端帽、颜色和层级；重复实验点与误差棒是独立图层。矢量转换后必须放大查看，防止细窄裁剪区域使竖线消失。
- 只有原始误差数据可用于真实统计绘制。由图片估计的误差棒必须注明估计，不得声称恢复了实验统计。

## 防止文字拥挤：创建时就处理

- 同一轴标题或公式创建为一个 Text 对象。使用完整 MathText，例如 `r'$j$ (mA cm$^{-2}$)'`；禁止用独立的 j、括号、单位和上下标按固定坐标拼接。文字换字体、加大字号或旋转时，上下标由排版引擎一起布局。
- PDF 中的字形坐标只用于识别原图内容和大致位置，不能在改变字体和字号后直接逐字重放。先恢复完整标签，核对指数、下标、负号和单位，再排版；自动包围盒检查无法验证化学式或单位是否正确。
- 普通多子图优先使用 GridSpec 与 constrained layout；手动定位的复现图必须重新预留左右边距、行列间距、双轴标题及图例所需空间。不能只放大字体而不调整版式。
- 消除拥挤的顺序：完整公式排版 → 增大 labelpad、图例内部间距和子图间距 → 长类别名称分行或合理旋转 → 调整图例位置及列数 → 必要时增大画布。不要把缩小字号、提高 DPI 或 bbox_inches='tight' 当成主要解决办法；后两者不能消除内部重叠。
- 图例统一放在图框内部。空间不足时扩大轴范围以增加图内顶部留白，或调整面板尺寸、图例列数及间距；不得自动移到框外，也不能压住数据、误差棒或双轴指示箭头。只改变显示范围，不修改数据数值。改变位置后保留系列与图例的一一对应。
- 补齐图框前先检查原有四边。原生 Matplotlib 图只设置 spines；PDF 路径重建只补缺边，并与现有轴线端点对齐。不得叠加第二个完整 Rectangle。重复的源轴线也应去重。

## 导出前的检查门槛

- 普通入口 scripts/render.py 和当前候选复现脚本均须调用 scripts/layout_checks.py 的 validate_figure，按最终 DPI 先 draw 再测量。新建模板和独立绘图脚本也必须在 savefig 前调用，不能仅引用这段文字。
- 脚本检查所有可见文字的实际包围盒，检测文字重叠和越界；检查已声明面板的缺边与重复边；对登记的矢量误差棒检查会吞掉细线的窄裁剪区域。错误写入 layout-checks.json，并阻止本次导出。图例覆盖数据线会记录为待复核警告。
- 普通坐标轴自动参与检查；在一个隐藏坐标轴上绘制整组矢量面板时，须通过 `fig._scientific_frames = [(ax, (x0, y0, x1, y1)), ...]` 登记各面板边界。特殊开放主题按显式 full_frame: false 处理。
- 矢量误差棒通过 `fig._scientific_errorbar_artists` 登记对应 PathPatch，不能用未登记、未检测冒充误差棒检查通过。原生误差棒仍需核对输入上下界、中心值、端帽及最终渲染效果。
- 原生 legend 根据渲染后的实际边界检查是否完全在坐标框内；自定义图例通过 `fig._scientific_legends = [(ax, [文字和符号对象...], 面板边界), ...]` 登记实际对象，同样逐项检测。框外图例阻止导出，不能只凭设置了 loc='upper left' 就认为在框内。
- 检查通过后查看整图，再放大所有复杂公式、密集图例、双轴和新增边框；不能只检查用户截图中的一处。包围盒对旋转文字可能保守报错，需实际调整或核实，不能静默关闭检查。
- 用户每指出一种可复用的错误，需完成四件事：修正当前图；写明原因与创建时的防御方法；把可检测项接入检查器；增加一个能复现旧错误的回归用例。无法可靠自动检测的部分明确列为人工复核项，不能声称已自动保证。
- `python scripts/test_layout_checks.py` 覆盖公式碎片重叠、文字越界、重叠及邻近双边框、倒置 y 坐标、细误差棒被裁剪、图例越框以及导出阻断等失败模式。修改检查器后运行这些用例，再用真实图验证。

## 完整坐标框（通用默认）

- 普通直角坐标数据图默认显示上、下、左、右四条边，构成完整闭合坐标框；不得默认隐藏上边和右边。
- 四边样式统一，不重复叠加外框。完整边框不等于四边都有刻度：刻度和数值默认仍只显示左、下两侧。
- 生成后检查四条 spine 的可见性，并查看最终导出图，避免主题切换后退回两边框。
- 所有图尽量保持封闭图框；只有用户明确指定、主题明确声明特殊开放边框，或极坐标、无轴示意等不适合矩形框的图型才例外。不能因绘图库默认样式而省掉两条边。
- 特殊开放主题应在主题配置中显式声明 appearance.full_frame: false，并在主题说明中记录理由；普通主题默认 true。

- 单图不能直接套用整组画布尺寸；以最终绘图区检查文字、线和 marker 的相对比例。
- x、y 轴标题必须清晰，不能显著偏小；60 × 50 mm 单图默认轴标题 10 pt，刻度文字 7 pt。
- 刻度只保留理解范围与趋势所需的数量，不因每个点有横坐标就逐点标注。
- 普通连续轴默认约 3～5 个可见主刻度，优先整洁数值；避免无意义小数和次刻度。
- 上述数量是默认目标，不是所有图的硬限制：类别名称、对数轴、特殊参考图及用户指定刻度按实际需求处理。
- 刻度减少只改变显示，不改变、删除、合并或重排数据；非单调 x 的连线顺序须按用户意图保留。
- 图例放在图框内真实空白区域，不覆盖线、点、误差条；不足时先增加图内留白。
- 每次改字号、刻度、尺寸或图例后，重新生成并查看，确认无裁切、拥挤或遮挡。
- 数据点不能一律采用实心圆。红青主题的普通多系列折线默认依次用空心方形、空心三角形，颜色与对应曲线一致，图例同步显示。
- 具体复现以参考面板为准：循环测试可为实心圆，Mott-Schottky 可为空心方形/三角形，不能把单一 marker 强加给全部图型。
- 普通曲线按每条系列的实际数据点数独立判断：少于 15 个点显示标记；15 个及以上完全不显示点标记，只绘制曲线。图例同步显示，不使用“每隔几个点显示”替代此规则。
- 全部数据仍参与绘制；隐藏标记不删除数据、不自动拟合或平滑。用户明确要求原图专属标记或散点图时按该任务要求处理。
